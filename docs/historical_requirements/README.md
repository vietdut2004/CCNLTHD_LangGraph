# Requirements lịch sử

Đây là các bản khai báo từ thí nghiệm/ví dụ trước. Bản nộp cuối chỉ cài
`requirements.txt`, dẫn tới `requirements-locked.txt` ở gốc repository.
Không cài chồng stack FAISS hoặc các recipe cũ vào môi trường BM25.
Các file được giữ nguyên để giải thích kết quả lịch sử ngày 24/10.
